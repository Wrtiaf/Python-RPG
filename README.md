# Трекер расходов

**Автор:** Менщиков Максим, ПА-15
**Задание:** Python RPG, уровень 0

Консольная программа на Python для учёта расходов. Пользователь вводит
категорию и сумму, программа суммирует траты по категориям и выводит отчёт.
Список категорий заранее не задан - новая категория создаётся автоматически,
а повторная увеличивает накопленную сумму.

## Запуск

```bash
python main.py
```

## Проверка

1. **Обычный сценарий:** добавить `еда` - `300`, `транспорт` - `50`,
   `еда` - `150`. В отчёте: `еда` - `450.0`, `транспорт` - `50.0`,
   итого - `500.0`.
2. **Необычный сценарий:** ввести сумму `abc` или `-10` - программа
   попросит положительное число и вернётся в меню. Пустая категория
   также не добавляется, программа не завершается.
